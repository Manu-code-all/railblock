## ⚠️ Do not edit the .pptx directly

`fill_ppt.py` **overwrites** `SIH2026_PS27_RailBlock.pptx` every time it runs.
Any hand edits made in PowerPoint are lost on the next build.

To change content, edit `fill_ppt.py` and rebuild.

## Where things live in `fill_ppt.py`

- **Team details** — top of the file (`TEAM_NAME`, `TEAM_ID`, `INSTITUTE`).
  `TEAM_ID` is blank; it prints "(assigned on SIH portal)" until filled in.
- **Palette** — the colour constants just below.
- **Slide content** — one clearly marked section per slide. Left-column text is a
  list of `("head", ...)` / `("b", ...)` / `("bg", ...)` tuples; diagrams are built
  from the `box()` / `arrow()` / `label()` / `bar()` helpers.

Design rule the deck follows: **minimal text on the left, one diagram filling the
right on every slide.**
