## Worked example — delete once you have your own

### Rule 0 — Adjacent-section clearance

- **Rule:** A block may not be taken on two adjacent sections of the same line
  at the same time, because trains need somewhere to be held.
- **Source:** *(example only — replace with a real citation)*
- **Status:** MISSING
- **How to model it:** For each pair of adjacent sections, forbid overlapping
  blocks. We already forbid two blocks on the *same* section; this extends the
  same idea to neighbours.
- **Why it matters:** Without it the plan can strand trains with nowhere to
  wait, which a railway officer would spot instantly.
